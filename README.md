# MOHAMMADHU IHZAN – Portfolio

Premium one-page portfolio. Pure static site: HTML5, CSS3, Vanilla JavaScript. No build step.

## Run
Open `index.html` (or use VS Code Live Server).

## Deploy (GitHub Pages)
Upload every file in this folder to the repository root, then Settings > Pages > Deploy from branch `main` / root.

## Edit content
Edit the arrays at the top of `script.js` (projects, skills, education, services).
